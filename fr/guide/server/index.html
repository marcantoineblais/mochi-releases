Gérer votre serveur

Surveillez votre serveur, réglez la conversion des vidéos et les sources d'information, mettez Mochi à jour et protégez vos données.

Vue d’ensemble et historique

Dans Administration :

  • Vue d’ensemble affiche qui est En cours de visionnement, le temps que chaque personne a passé à regarder (Visionnement par personne) et les tâches en cours.
  • Historique affiche ce que chacun a regardé, et les changements faits par les administrateurs.

Tâches d’entretien

Mochi se tient à jour grâce à des tâches qu’il lance de lui-même. L’onglet Entretien les affiche avec leur dernière exécution. Lancer en démarre une tout de suite, et Arrêter l’interrompt.

Conversion des vidéos

Mochi lit les fichiers tels quels chaque fois que l’appareil le peut. Sinon, il convertit la vidéo à la volée. Dans Administration, sous Serveur, puis Lecture :

  • Accélération matérielle : Automatique utilise votre carte graphique quand elle réussit les tests de Mochi. Tests des cartes graphiques montre ce qu’elle peut faire. Avec le processeur seulement, Mochi suffit pour une ou deux personnes dont la vidéo est convertie en même temps.
  • Conversions simultanées : le nombre de vidéos que Mochi convertit en même temps.

Sources d’information

Les titres, les résumés et les images viennent de TMDB, d’AniDB, de TVmaze, d’AniList et de Wikipédia, et ceux de la musique, de MusicBrainz et du Cover Art Archive, sans rien configurer. Quelques sources demandent votre propre clé gratuite, à entrer dans l’onglet Serveur :

  • Clé OMDb : pour les notes IMDb et Rotten Tomatoes. Obtenez-en une sur omdbapi.com.
  • Clé Fanart.tv : pour les logos, les arrière-plans et les photos d’artistes.
  • Clé Last.fm : pour les biographies des artistes et les genres musicaux.

Fichier de paramètres et ports

Les paramètres avancés se trouvent dans le fichier de paramètres de Mochi :

  • Windows : C:\ProgramData\Mochi\mochi.conf. Après une modification, redémarrez Mochi à partir de son icône dans la barre des tâches.
  • Linux : /etc/mochi/mochi.conf, puis sudo systemctl restart mochi.
  • Docker : les fichiers .env et compose.yml.

Mochi répond sur le port 6624. Sur votre réseau, il s’annonce aussi sur le port UDP 5353, pour que les applications le trouvent d’elles-mêmes.

Mettez Mochi à jour

  • Windows : lancez le nouvel installateur. Il garde vos paramètres, vos données et vos dossiers.
  • Linux : installez le nouveau paquet .deb ou .rpm.
  • Docker : téléchargez la nouvelle image et redémarrez, avec docker compose pull && docker compose up -d.

Les pages ouvertes se rechargent d’elles-mêmes une fois le serveur mis à jour.

Sauvegardes

Sauvegarder la base de données enregistre chaque jour une copie de la base de données dans le dossier de données de Mochi, et une autre avant chaque mise à jour qui la modifie. Les 7 plus récentes sont gardées.

Les sauvegardes se trouvent dans le dossier backups du dossier de données de Mochi, que seul un administrateur peut ouvrir : C:\ProgramData\Mochi\backups sur Windows, /var/lib/mochi/backups sur Linux. Pour remettre le serveur comme il était :

  1. Copiez une sauvegarde hors de ce dossier, en tant qu’administrateur ou avec sudo, dans un dossier que vous pouvez ouvrir, comme vos Documents.
  2. Allez dans Administration, puis Serveur, choisissez Importer sous Importer votre bibliothèque, puis ce fichier.

Tout ce qui a changé depuis cette sauvegarde sera perdu.

Déménager Mochi sur un autre ordinateur

  1. Sur l’ancien serveur, allez dans Administration, puis Serveur, et choisissez Exporter sous Exporter votre bibliothèque. Faites-le dans un navigateur, sur un ordinateur. Le fichier contient le compte de chaque personne et les clés du serveur : gardez-le en lieu sûr.
  2. Installez Mochi sur le nouvel ordinateur. Au premier écran de configuration, choisissez Importer votre bibliothèque, puis le fichier.
  3. Une fois l’importation terminée, ajoutez les dossiers de chaque bibliothèque dans Administration, sous Bibliothèques.

L’exportation contient les comptes, les bibliothèques, l’historique de visionnement, les listes de lecture, les réglages et les images. Vos fichiers multimédias n’y sont pas : s’ils changent d’ordinateur eux aussi, copiez-les vous-même.

Mot de passe oublié?

Un administrateur peut donner un nouveau mot de passe à n’importe qui dans Personnes. Si vous êtes le seul administrateur, réinitialisez le vôtre sur le serveur, dans un terminal :

  • Windows, dans une invite de commandes ouverte en tant qu’administrateur : "C:\Program Files\Mochi\mochi.exe" reset-password <nom d'utilisateur>
  • Linux : sudo -u mochi mochi reset-password <nom d'utilisateur>

Mochi demande deux fois le nouveau mot de passe, puis déconnecte ce compte partout.

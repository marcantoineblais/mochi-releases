Personnes et profils

Donnez à votre famille et à vos amis leur propre profil, choisissez ce qu'ils voient et connectez un téléviseur avec votre téléphone.

Ajoutez une personne

Chacun a son propre profil, sa progression et ses préférences. Allez dans Administration, puis Personnes, et choisissez Ajouter une personne. Donnez-lui un nom, un nom d’utilisateur, un mot de passe d’au moins 12 caractères et une couleur d’avatar.

Pour chaque personne, vous pouvez ensuite choisir :

  • Accès à toutes les bibliothèques, ou seulement à celles que vous cochez.
  • Limite de qualité : limite ses vidéos, par exemple pour économiser la bande passante.
  • Administrateur : lui permet de gérer les bibliothèques, les personnes et le serveur. Donner des droits d’administrateur demande votre propre mot de passe.
  • Désactivé : elle ne peut plus se connecter, et son historique est conservé.

Envoyez-lui l’adresse du serveur avec son nom d’utilisateur et son mot de passe. Pour la famille et les amis qui habitent ailleurs, Mochi a d’abord besoin d’une adresse https : consultez Regarder hors de la maison.

Qui regarde?

Chaque appareil se souvient des personnes qui s’y sont connectées. L’écran de connexion affiche leurs profils : choisissez le vôtre pour commencer à regarder.

  • Ajouter quelqu’un connecte une autre personne sur cet appareil.
  • Retirer de cet appareil enlève un profil de la liste.
  • Changer de profil, dans le menu du profil, ramène aux profils.

Toute personne qui utilise un appareil où vous êtes connecté peut ouvrir votre profil. Pour l’éviter, activez Demander mon mot de passe quand je choisis mon profil dans Paramètres, sous Profil. Un profil d’administrateur demande toujours le mot de passe.

Connectez un téléviseur avec votre téléphone

Entrer un mot de passe avec la télécommande, c’est long. Utilisez plutôt votre téléphone :

  1. Sur le téléviseur, choisissez Ajouter quelqu’un. Il affiche un code QR et un code à entrer.
  2. Sur votre téléphone, ouvrez Mochi, puis le menu du profil, et choisissez Connecter un autre appareil.
  3. Choisissez Numériser le code et pointez le téléphone vers le téléviseur, ou entrez le code.
  4. Choisissez Approuver. Le téléviseur ouvre Mochi avec votre profil.

N’approuvez que si le code s’affiche sur un écran devant vous. Si le téléviseur et le téléphone ne sont pas sur le même réseau, Mochi vous demande d’entrer le code affiché.

Vos paramètres

Chaque personne règle ses préférences dans Paramètres :

  • Profil : votre nom et votre Langue. Mochi et vos titres s’affichent dans cette langue sur tous vos appareils.
  • Lecture : vos choix d’audio et de sous-titres. Consultez Regarder.
  • Accueil : l’ordre des rangées de votre écran d’accueil.

Mots de passe et appareils

Dans Paramètres, sous Mot de passe :

  • Changer le mot de passe déconnecte vos autres appareils.
  • Appareils connectés affiche vos appareils. Choisissez Déconnecter à côté de l’un d’eux, ou Se déconnecter partout.

En tant qu’administrateur, vous pouvez donner un nouveau mot de passe à quelqu’un dans Personnes, et voir Où cette personne est connectée.

Vous avez oublié le mot de passe de l’administrateur? Réinitialisez-le sur le serveur : consultez Gérer votre serveur.

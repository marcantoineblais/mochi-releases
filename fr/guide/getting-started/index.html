Premiers pas

Installez Mochi, créez votre compte et ajoutez votre première bibliothèque.

Ce qu’il vous faut

  • Un ordinateur qui reste allumé, avec vos films, vos séries ou votre musique, sur cet ordinateur ou dans un dossier partagé de votre réseau, comme un NAS. Mochi fonctionne sur Windows 10 et 11 (64 bits), sur Linux (x64 ou ARM64) et dans Docker.
  • Un appareil pour regarder : n’importe quel navigateur récent, ou l’application Mochi pour Windows ou Android.

Cet ordinateur devient votre serveur Mochi. Tous les autres appareils s’y connectent.

Installez le serveur

Téléchargez l’installateur pour votre système sur la page de téléchargement.

Windows

  1. Lancez l’installateur.
  2. À l’étape Choisissez les dossiers de Mochi, cochez les dossiers qui contiennent vos films, vos séries et votre musique. Mochi peut utiliser ce qui est coché, et rien d’autre sur cet ordinateur.
  3. Cochez Permettre aux autres appareils du réseau de joindre Mochi pour regarder sur votre téléphone ou votre téléviseur.

Mochi démarre avec Windows et fonctionne en arrière-plan. Son icône dans la barre des tâches indique s’il est en marche et permet de l’ouvrir, de le redémarrer ou de l’arrêter. Pour changer de dossiers plus tard, relancez l’installateur et choisissez Modifier les réglages.

Linux

Installez le paquet de votre distribution :

sudo apt install ./mochi_<version>_amd64.deb      # Debian, Ubuntu
sudo dnf install ./mochi-<version>-1.x86_64.rpm   # Fedora, RHEL

Sur Fedora et RHEL, installez d’abord ffmpeg à partir de RPM Fusion, pour que Mochi puisse convertir les vidéos.

Mochi fonctionne comme un service, avec son propre compte mochi. Assurez-vous que ce compte peut lire vos dossiers de médias.

Docker

Suivez les étapes de la page de téléchargement : enregistrez le fichier compose.yml, indiquez le mot de passe de la base de données et le chemin de vos médias dans .env, puis démarrez Mochi.

Ouvrez Mochi

  • Sur le serveur lui-même, ouvrez http://localhost:6624 dans un navigateur.
  • Sur un autre appareil de votre réseau, remplacez localhost par le nom ou l’adresse IP du serveur, par exemple http://192.168.1.20:6624.

Configurez Mochi

La première visite vous guide en quatre étapes.

  1. Bienvenue sur Mochi : choisissez votre langue et donnez un nom au serveur. Ce nom s’affiche à l’écran de connexion et sur vos téléviseurs.
  2. Votre compte : vous en devenez l’administrateur. Le mot de passe doit compter au moins 12 caractères. Si vous faites la configuration à partir d’un autre appareil, Mochi demande aussi un Code de configuration. Il se trouve dans le journal de Mochi, sur une ligne comme setup_code=ABCD-2345 :
    • Windows : C:\ProgramData\Mochi\logs\mochi.log
    • Linux : sudo journalctl -u mochi
    • Docker : docker logs mochi
  3. Votre première bibliothèque : donnez-lui un nom, choisissez son Contenu (films, séries ou musique) et ses dossiers. Vous pouvez aussi choisir Plus tard et ajouter vos bibliothèques ensuite.
  4. C’est prêt! : choisissez Commencer à regarder. Mochi parcourt vos fichiers et récupère les affiches, les résumés et les acteurs. Les titres apparaissent au fur et à mesure.

Vous déménagez Mochi d’un autre ordinateur? Choisissez plutôt Importer votre bibliothèque au premier écran. Consultez Gérer votre serveur.

Prochaines étapes

  • Organisez vos bibliothèques pour que Mochi reconnaisse chaque titre.
  • Ajoutez votre famille et vos amis, chacun avec son profil.
  • Installez les applications sur votre ordinateur, votre téléphone ou votre téléviseur.

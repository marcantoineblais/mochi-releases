Télécharger Mochi

Installez Mochi sur l'ordinateur qui contient vos films et vos séries, puis ouvrez-le sur n'importe quel appareil, dans le navigateur ou dans l'application Mochi.

ServeurApplications

Les applications lisent presque tous les fichiers tels quels, en qualité d'origine. Elles sont facultatives : Mochi fonctionne aussi dans n'importe quel navigateur récent.

Application Windows

Pour Windows 10 (version 2004 ou plus récente) et Windows 11, 64 bits. Elle lit presque tous les fichiers en qualité d'origine, et les touches multimédias de votre clavier contrôlent la musique.

  • Elle s'installe pour votre compte seulement, sans droits d'administrateur.
  • Sur Windows 10, l'installateur propose d'installer Microsoft Edge WebView2 s'il est absent.
  • Au premier lancement, choisissez votre serveur dans la liste, ou entrez son adresse, comme 192.168.1.20.
Télécharger pour Windowsx64 · 95 Mo

Android

Pour les téléphones et les tablettes sous Android 8.0 ou plus récent.

Télécharger pour AndroidAPK · 24 Mo

Sur un téléphone ou une tablette

  1. Ouvrez cette page sur le téléphone et touchez Télécharger pour Android.
  2. Ouvrez le fichier téléchargé. Si Android le demande, autorisez votre navigateur à installer des applications inconnues, puis touchez Installer.
  3. Ouvrez Mochi et choisissez votre serveur.

Android TV

Pour les téléviseurs sous Android 8.0 ou plus récent, Google TV compris. C'est la même application que sur les téléphones et les tablettes.

Télécharger pour Android TVAPK · 24 Mo

Sur le téléviseur

  1. Sur le téléviseur, installez l'application gratuite Downloader à partir du Play Store.
  2. Dans les Paramètres du téléviseur, autorisez Downloader à installer des applications inconnues. Sur Google TV, ce réglage se trouve dans Applications, puis Sécurité et restrictions, puis Sources inconnues. Sur les autres téléviseurs Android, il se trouve dans Préférences de l'appareil, puis Sécurité et restrictions.
  3. Dans Downloader, entrez mochiplayer.com/tv et installez l'application.
  4. Ouvrez Mochi à partir de vos applications et choisissez votre serveur.

Confidentialité

Ce que le serveur et les applications Mochi envoient, et à qui.

Mochi est un logiciel que vous faites fonctionner vous-même : un serveur sur votre propre ordinateur, et des applications qui s’y connectent. Personne n’exploite un service Mochi qui recevrait ce que vous y faites. Il n’y a ni publicité ni compte Mochi, et rien de ce que vous faites dans Mochi ne parvient aux personnes qui le créent.

Ce que les applications envoient

Les applications Mochi pour Android, Android TV et Windows communiquent avec le serveur Mochi dont vous entrez l’adresse, exploité par vous ou par la personne qui vous y a donné accès. Elles lui envoient :

  • vos identifiants de connexion, le nom de votre appareil et vos réglages
  • ce que vous lisez, l’endroit où vous vous arrêtez et le contenu de votre file d’attente musicale

Ces données restent sur ce serveur. Son propriétaire décide qui y a un compte et peut supprimer des comptes.

Pour trouver les serveurs de votre réseau domestique, les applications demandent aux appareils de ce réseau lesquels font fonctionner Mochi. Rien de cette recherche ne quitte le réseau.

Numériser un code de connexion

Sur un téléphone Android, Numériser le code lit un code QR avec le lecteur de codes de Google. Google reçoit le modèle du téléphone, sa version d’Android et les erreurs que rencontre le lecteur, à des fins de diagnostic et de statistiques d’utilisation. Il ne reçoit ni l’image ni le code.

Mises à jour

L’application Windows, l’application Android de mochiplayer.com et le serveur lisent https://mochiplayer.com/updates.json pour savoir si une nouvelle version est sortie. Cette demande ne contient aucune information sur vous. L’application Android de Google Play reçoit ses mises à jour par Google Play.

Ce que le serveur consulte

Le serveur cherche les titres de vos bibliothèques auprès des sources d’information nommées dans Paramètres → À propos, comme TMDB et MusicBrainz, pour obtenir affiches, résumés et pochettes d’albums. Il leur envoie des titres et leurs identifiants, jamais qui les regarde.

La démo

La démo de l’application Android fonctionne entièrement sur l’appareil. Elle n’envoie rien.

Enfants

Mochi n’est pas destiné aux enfants de moins de 13 ans. Le propriétaire d’un serveur décide des bibliothèques que voit chaque profil.

Changements

Cette page change quand les applications ou le serveur envoient quelque chose de nouveau, avant la sortie de cette version.

Getting started

Install Mochi, create your account and add your first library.

What you need

  • A computer that stays on, with your movies, shows or music on it or on a shared folder of your network, such as a NAS. Mochi runs on Windows 10 and 11 (64-bit), on Linux (x64 or ARM64) and in Docker.
  • Something to watch on: any recent web browser, or the Mochi app for Windows or Android.

That computer becomes your Mochi server. Everyone else connects to it.

Install the server

Get the installer for your system on the download page.

Windows

  1. Run the installer.
  2. On Choose Mochi’s folders, tick the folders with your movies, shows and music. Mochi can use what’s ticked, and nothing else on this computer.
  3. Tick Let other devices on this network reach Mochi to watch from your phone or TV.

Mochi starts with Windows and runs in the background. Its icon in the taskbar shows whether it’s running, and opens, restarts or stops it. To change the folders later, run the installer again and choose Change settings.

Linux

Install the package for your distribution:

sudo apt install ./mochi_<version>_amd64.deb      # Debian, Ubuntu
sudo dnf install ./mochi-<version>-1.x86_64.rpm   # Fedora, RHEL

On Fedora and RHEL, install ffmpeg from RPM Fusion first, so Mochi can convert videos.

Mochi runs as a service under its own mochi account. Make sure that account can read your media folders.

Docker

Follow the steps on the download page: save the compose.yml file, set the database password and the path to your media in .env, then start it.

Open Mochi

  • On the server itself, open http://localhost:6624 in a browser.
  • On another device of your network, use the server’s name or IP address instead of localhost, for example http://192.168.1.20:6624.

Set up Mochi

The first visit walks you through four steps.

  1. Welcome to Mochi: pick your language and give the server a name. The name shows on the sign-in screen and on your TVs.
  2. Your account: you become the administrator. The password needs at least 12 characters. If you’re setting up from another device, Mochi also asks for a Setup code. It’s in Mochi’s log, on a line like setup_code=ABCD-2345:
    • Windows: C:\ProgramData\Mochi\logs\mochi.log
    • Linux: sudo journalctl -u mochi
    • Docker: docker logs mochi
  3. Your first library: give it a name, pick what it Contains (movies, shows or music) and choose its folders. You can also choose Skip for now and add libraries later.
  4. All set!: choose Start watching. Mochi looks through your files and fetches posters, summaries and cast. Titles appear as they’re found.

Moving Mochi from another computer? Choose Import your library on the first screen instead. See Running your server.

Next steps

Libraries and files

Organize your folders so Mochi recognizes every title, and fix the ones it gets wrong.

Add a library

A library gathers one kind of media, movies, shows or music, from the folders you choose. Go to Administration, then Libraries, and choose Add a library.

  • Name: what everyone sees, like Movies or Cartoons.
  • Contains: movies, shows or music.
  • Folders: choose Add a folder. On Windows, the list shows the folders you ticked in the installer. For a shared folder on a NAS, choose Add a network folder and type its address, like \\nas\media, with the account that opens it. The password is kept encrypted on the server.
  • Colour: the library’s colour across Mochi.
  • Information sources: where titles, summaries and pictures come from. Each piece of information comes from the first source that has it, so drag the one you trust most to the top.
  • Keep artwork with the media: saves posters and backgrounds in the library’s folders, and uses the pictures already there.

Movie and show libraries have a few more options:

  • Age ratings: which country’s ratings to show.
  • Timeline previews: shows a picture of the video above the timeline while you seek.
  • Keep timeline previews with the media: saves each video’s previews in a folder next to it.
  • Find intros and credits (shows): finds the intros and credits in episodes, for the Skip buttons.
  • Find credits (movies): finds each movie’s credits, for the Skip button.
  • Show missing episodes (shows): lists the episodes you have no file for, and those still to come.

Several libraries of the same kind can show as one. Tick them under Display together in the Libraries tab.

Name your files

Mochi recognizes your titles from their folder and file names. Give each movie its own folder with its year, and each show a folder per season:

Movies/
  The Matrix (1999)/
    The Matrix (1999).mkv
Shows/
  Breaking Bad/
    Season 1/
      Breaking Bad S01E01.mkv
      Breaking Bad S01E02.mkv

Season folders can be named Season 1, Saison 1 or S01. Subtitles next to a video, with the same name and a language code (The Matrix (1999).fr.srt), are picked up with it.

Music is sorted from the songs’ own tags. Folders named Artist/Album fill in what the tags leave out.

Extras go in a folder inside the movie’s or show’s folder, named Trailers, Featurettes, Behind the scenes, Deleted scenes, Interviews or Extras. A file ending in -trailer also counts. They show under Extras on the title’s page.

To force a match, add the title’s id to its folder name: The Matrix (1999) [tmdb-603] or Frieren [anidb-17617].

New files show up on their own

Mochi watches your library folders. A new file appears about 30 seconds after it finishes copying, with its poster and summary. Shared network folders don’t always report changes, so Mochi also scans every library every 6 hours. To scan right away, choose Scan now next to the library.

When Mochi gets a title wrong

Files Mochi can’t place are listed under Needs your attention, then Unmatched, in the Libraries tab. Move them into one of the layouts above, or choose Identify and say what each one is.

A title matched to the wrong movie or show: open its page, choose More, then Fix information.

  • The Matches tab shows what each source matched the title to. Choose Change to search the source again, or paste the title’s id from that site. Let Mochi find it goes back to automatic.
  • The Information tab lets you pick where each piece comes from, or write Your own text and upload Your own picture.
  • If a show’s files follow DVD order or count episodes across seasons, pick it under Episode order.

Other tools in the same More menu:

  • Change pictures: choose another poster, background or logo. Your pick stays when the information is refreshed.
  • Refresh information: downloads the title’s information again.
  • Edit intro and credits: set where the Skip buttons start and end, as minutes:seconds. Add credits adds another credits block, for credits that come back after a scene.

To start over for a whole library, choose Edit library, then Refresh all information. What you picked yourself stays.

Delete titles and libraries

  • Delete library removes its titles from Mochi. The files stay where they are.
  • Delete movie…, Delete episode… and the like, in a title’s More menu, delete the files from disk with their subtitles and pictures. This can’t be undone. Everyone’s progress is kept in case the file comes back.

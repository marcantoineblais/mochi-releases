Privacy

What the Mochi server and apps send, and where it goes.

Mochi is software you run yourself: a server on your own computer, and apps that connect to it. Nobody runs a Mochi service that receives what you do in it. There are no ads and no Mochi account, and nothing you do in Mochi reaches the people who make it.

What the apps send

The Mochi apps for Android, Android TV and Windows talk to the Mochi server whose address you enter, run by you or by the person who shared it with you. They send it:

  • your sign-in, the name of your device and your settings
  • what you play, where you stop and what’s in your music queue

That data stays on that server. Its owner decides who has an account there and can delete accounts.

To find servers on your home network, the apps ask the devices on that network which ones run Mochi. Nothing about it leaves the network.

Scanning a sign-in code

On an Android phone, Scan the code reads a QR code with Google’s code scanner. Google receives the phone’s model, its Android version and any errors the scanner meets, for diagnostics and usage statistics. It doesn’t receive the picture or the code.

Updates

The Windows app, the Android app from mochiplayer.com and the server read https://mochiplayer.com/updates.json to find out whether a new version is out. The request carries no information about you. The Android app from Google Play gets its updates from Google Play.

What the server contacts

The server looks up the titles in your libraries on the information sources listed in Settings → About, such as TMDB and MusicBrainz, to fetch posters, summaries and album covers. It sends them titles and their IDs, never who watches them.

The demo

The demo in the Android app runs entirely on the device. It sends nothing anywhere.

Children

Mochi isn’t made for children under 13. A server’s owner decides which libraries each profile sees.

Changes

This page changes when the apps or the server send something new, before that version is released.
